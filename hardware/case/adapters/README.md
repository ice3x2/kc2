# 중앙 구멍 링 어댑터 — CON-ARCH-004

V1용과 MX용의 중앙 관통 링입니다. 키캡 변환 어댑터나 전기 접점 변환 부품은 아닙니다.
현재 조립·주문 파일은 프로젝트 루트의 [order.md](../../../order.md)를 기준으로 선택하세요.

| mm | V1 | MX |
|---|---:|---:|
| 내경 (초기 시험값) | 3.50 | 4.10 |
| 삽입부 외경 | 4.80 | 4.80 |
| 삽입 길이 | 1.20 | 1.20 |
| 상단 테두리 외경 | 6.00 | 6.00 |
| 상단 테두리 두께 | 0.20 | 0.20 |

내경은 선택 부품의 실측값이 아니라 조정 가능한 초기 시험 치수입니다.
명목 Ø5.00 PCB 구멍에 넣는 구조이며, 출력 수축·내경 오차에 따라 조정이 필요합니다.
MX 링의 방사방향 벽 두께는 0.35 mm이므로 0.25 mm 노즐을 권장합니다.
0.4 mm 노즐에서는 가변 선폭/얇은 벽 기능과 실제 슬라이싱 결과를 확인해야 합니다.

## 인쇄

STL은 mm 단위, 넓은 테두리가 바닥인 방향입니다. 조립할 때 뒤집어 테두리를 PCB 위에 둡니다.
첫 레이어와 이후 레이어 모두 0.20 mm, 크기 100%, raft 및 support 없음으로 설정하세요.
테두리는 첫 한 층만, 링 전체 높이 1.40 mm는 총 7층입니다.
가운데 구멍을 막는 막은 없습니다. STL 자체는 레이어 수를 지정하지 않으므로
미리보기에서 테두리가 첫 층에만 있는지 확인하세요. 보정/브림으로 얇은 테두리를 손상시키지 마세요.

## 제한

V1의 측면 위치결정 돌기는 이 링 자체로 해결되지 않습니다. 정식 r3 이후 PCB에는
Ø2.60 mm / 로컬 X±5.45 mm 공용 측면 구멍이 반영되었습니다. 이전 PCB와 혼용하지 마세요.
완전 안착 및 Choc 소켓 접점 삽입 깊이의 실제 부품 검증은 여전히 필요합니다.
PCB를 임의로 드릴 가공하거나 핀을 강제로 밀지 마세요.
테두리는 스위치 아래에 0.20 mm를 차지합니다. MX 소켓 플랜지와 자동으로 높이가 더해지는 것은
아니며, 실제 하부 접촉면을 기준으로 안착을 확인해야 합니다. 추가 높이·클립·접점·키캡 간섭은 미검증입니다.

재생성: `python -B -m tools.generate_kc2_ring_adapters`

검사: `python -B -m unittest tools.test_kc2_ring_adapters`
