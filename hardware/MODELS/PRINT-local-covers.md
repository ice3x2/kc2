# 국소 가림벽 하우징 인쇄·조립 안내

요구사항: `CON-ARCH-006`, `CON-ARCH-007`, `OPS-ARCH-006`. 기준: 기존 r5 (`cc854a3`).

이 개정은 하판 위에 PCB를 올리는 기존 구조를 유지합니다. PCB를 새로운 외벽 안에 끼워 넣거나, 상판을 새 하판 벽에 안착시키는 구조가 아닙니다.
이전의 전체 외벽·확대된 좌우 간격 개정(`2268492`)은 철회됐습니다.

## 파일 확인

인쇄 전 저장소 루트에서 다음 검증이 통과해야 합니다. 게시 manifest가 없거나 실패하면 아직 최종 게시 전이거나 파일이 변경된 상태입니다.

```powershell
python -B -m tools.publish_kc2_local_covers --verify
```

검증은 설계 형상과 파일의 일치 여부를 확인합니다. 실제 출력 강도, 구매한 부품 및 키캡의 적합성은 별도 실물 확인이 필요합니다.

## 인쇄할 세트

하판은 무자석 또는 `_magnetic` 중 한 열만 골라 각 1개씩 인쇄합니다.

| 부품 | 무자석 | 자석 홈 |

| 왼쪽 하판 | [STL](kc2_left_lower_housing.stl) | [STL](kc2_left_lower_housing_magnetic.stl) |
| 오른쪽 하판 A | [STL](kc2_right_lower_housing_part_a.stl) | [STL](kc2_right_lower_housing_part_a_magnetic.stl) |
| 오른쪽 하판 B | [STL](kc2_right_lower_housing_part_b.stl) | [STL](kc2_right_lower_housing_part_b_magnetic.stl) |

공통 MX 상판은 다음 3개를 각 1개씩 사용합니다. 하판과 합쳐 6개입니다.

- [왼쪽 MX 상판](kc2_left_mx_upper_housing.stl)
- [오른쪽 MX 상판 A](kc2_right_mx_upper_housing_part_a.stl)

## 그대로 유지하는 조립 구조

- 바닥 두께 1.20 mm, 외면 Z−2.20 / 내면 Z−1.00 mm.
- 기존 받침 위 PCB 아래·위 면 Z2.50 / 4.10 mm.
- MX 보강판 아래·위 면 Z7.80 / 9.30 mm.
- 기존 70개 스위치 위치, 왼쪽 8개·오른쪽 9개 체결 위치와 나사 받침.
- 기존 좌우 결합 위치와 명목 중앙 키캡 간격 1.80 mm. 확대된 6.40 mm 간격은 사용하지 않습니다.
- 명목 M1.4×7.50 mm 나사. 8/9/10 mm로 임의 대체하지 않습니다.
- 기존 오른쪽 분할 이음과 여유. 가림부가 이음에 걸리는 곳도 분리해서 인쇄합니다.

하판의 가림 대상은 왼쪽 5곳·오른쪽 7곳의 소켓 측면 개구부입니다. 소켓·납땜 여유 공간을 채우지 않고, 그 바깥에 얇은 가림부를 더합니다. 하판 가림부는 PCB 받침 높이 Z2.50을 넘지 않습니다.
무자석/자석 버전 모두 같은 국소 가림부를 사용하며 기존 자석 홈은 유지합니다.

MX 상판에는 주변 스위치 옆의 노출 구간을 가리는 분절된 가림부가 달립니다. 하판의 12곳만 복제한 형상도, PCB·컨트롤러 전체를 감싸는 상자도 아닙니다. 가림부 아래 끝은 Z4.40으로 PCB 윗면에서 0.30 mm 떨어져 있고, 기존 나사 받침이 상판 높이를 결정합니다.
스위치 몸체를 피해야 하는 곳만 국소적으로 돌출되며, 돌출부 위에도 같은 높이의 얇은 지붕을 연결해 상판을 뒤집어 출력할 때 연결되지 않은 벽이 시작되지 않도록 합니다. 컨트롤러 방향과 기능·조립에 필요한 개구부는 남깁니다. 지붕·가림부와 실제 키캡 안쪽의 적합성은 실물 확인 대상입니다.

## 출력과 조립 시 주의

하판은 바닥 외면을 베드에 놓습니다. 상판은 보강판 윗면을 베드에 놓고 받침이 위를 향하도록 뒤집습니다. mm 단위·100% 배율로 출력하며 전체 크기를 늘려 공차를 맞추지 않습니다.

얇은 가림벽의 명목 두께는 약 0.40 mm입니다. 슬라이서 층 미리보기에서 벽이 생략되거나 끊어지지 않는지 확인하세요. 프린터·노즐·선폭·재료가 지정되지 않았으므로 강도나 출력 성공을 보증하지 않습니다.

PCB 납땜은 하판 밖에서 합니다. 기존 조건대로 PCB 아래 핀·납·부품 돌출이 최대 2.90 mm 이내인지 실측하고, 몸체나 접점을 깎거나 배터리를 압축해 맞추지 않습니다.
하판에 PCB를 올리고 기존 받침에 제대로 닿는지 확인한 다음 MX 상판을 장착합니다. 틈이 맞지 않을 때 나사 힘으로 강제로 누르지 마세요.

자석은 Ø2×1 mm이며 기존 Ø2.4×깊이 1.2 mm 홈과 공차 시험편을 사용합니다. 극성·접착·흡착력·이탈 방지는 실제 출력물로 확인해야 합니다.
실리콘 발은 기존 평평한 바닥의 접착 위치에 붙이고 이음과 모서리를 피합니다.

키캡 전체 이동, 실제 헤더·케이블·배터리·배선 간섭, 나사 토크와 반복 조립, 출력 변형·강도, 자석 흡착력 및 RF는 실물 확인 항목입니다. PCB·주문된 거버는 변경하지 않으며 이번 하우징 개정은 새 PCB 제작 승인이 아닙니다.

서비스 접근 검사에서 새 가림벽이 추가하는 간섭과 기존 구조의 겹침을 구분합니다. 기존 상판 일부는 보수적으로 잡은 USB 케이블·전원 조작·리셋 도구 접근 영역과 겹칩니다. 따라서 기존 형상을 유지했다는 결과를 모든 케이블·손가락·도구가 자유롭게 접근한다는 보증으로 해석하지 마세요. 실제 부품과 도구로 조작성을 확인해야 합니다.
