# 연속 벽 하우징 인쇄·조립 안내

요구사항: `CON-ARCH-006`, `CON-ARCH-007`, `OPS-ARCH-006`. 개정: 2026-09-09.

상판에 벽을 추가하여 하판 벽에 직접 얹히도록 했습니다. 하판도 소켓 등이 측면으로 보이지 않도록 외벽을 연결했습니다.
USB·POWER 접근 홈, RESET 탐침 구멍과 오른쪽 A/B 인쇄 이음부는 의도된 예외입니다.
이전 열린 하우징과 새 상·하판을 섞지 마세요. PCB·주문된 거버는 바꾸지 않습니다.

## 먼저 파일 검증

저장소 루트에서 아래 명령이 통과하고 [게시 manifest](kc2_enclosure_manifest.json)가 현재 파일과 일치하는지 확인합니다.
manifest가 없거나 실패하면 아직 배포가 완료되지 않았거나 파일이 바뀐 상태이므로 인쇄를 보류하세요.

```powershell
python -B -m tools.publish_kc2_enclosure --verify
```

검증은 디지털 파일·증거의 일치 여부를 확인합니다. 실제 출력 강도, 구매한 헤더·케이블·배터리·키캡까지 실물 검증한 뜻은 아닙니다.
검사 범위와 남은 조건은 [검증 기록](../../docs/reports/enclosed-housing-20260909/README.md)을 확인하세요.

## 인쇄할 파일

하판은 아래 두 옵션 중 **한 열만** 선택하여 각 1개씩 인쇄합니다.

| 부품 | 무자석 하판 | 자석 홈 하판 |
|---|---|---|
| 왼쪽 | [STL](kc2_left_lower_housing.stl) | [magnetic STL](kc2_left_lower_housing_magnetic.stl) |
| 오른쪽 A | [STL](kc2_right_lower_housing_part_a.stl) | [magnetic STL](kc2_right_lower_housing_part_a_magnetic.stl) |
| 오른쪽 B | [STL](kc2_right_lower_housing_part_b.stl) | [magnetic STL](kc2_right_lower_housing_part_b_magnetic.stl) |

두 옵션 모두 아래 공통 MX 상판 3개를 각각 1개씩 사용합니다. 선택한 하판과 합쳐 총 6개입니다.

- [왼쪽 MX 상판](kc2_left_mx_upper_housing.stl)
- [오른쪽 MX 상판 A](kc2_right_mx_upper_housing_part_a.stl)
- [오른쪽 MX 상판 B](kc2_right_mx_upper_housing_part_b.stl)

오른쪽 전체 STEP/F3D에는 A/B 두 솔리드가 들어 있습니다. 150 mm 프린터에는 나뉜 STL을 사용하세요.
각 STL은 150 mm 범위 이내입니다. STEP/F3D는 편집·확인용입니다.
선택용 [MX 링](adapters/kc2_mx_ring_cap_020.stl), [V1 링](adapters/kc2_v1_ring_cap_020.stl)은 기본 하우징 세트에 포함되지 않습니다.
이 안내의 기본 조립은 MX용이며 링이 다른 스위치의 핀·소켓 호환성을 보장하지 않습니다.

## 치수와 맞닿는 면

| 항목 | 명목 설계값 |
|---|---|
| 하판 바닥 | Z−2.20~−1.00, 두께 1.20 mm |
| PCB 아래·위 면 | Z2.50 / 4.10 mm |
| 상·하판 벽 맞닿음 | Z4.10 mm |
| 하판 전체 높이 | 6.30 mm |
| MX 보강판 아래·위 면 | Z7.80 / 9.30 mm |
| 상판 전체 높이 | 5.20 mm |
| 바닥부터 보강판까지 | 11.50 mm, 실리콘 발·키캡 제외 |
| 외벽 두께 | 기본 약 0.80 mm, 중앙 제한 구간 최소 0.40 mm |
| PCB·부품과 새 벽 여유 | 명목 최소 0.30 mm |
| 좌우 조립 시 중앙 키캡 간격 | 명목 6.40 mm |

연속 벽을 확보하기 위해 이전 외곽과 중앙 간격을 확장했습니다. 각 반쪽 내부 키 위치는 그대로입니다.
설계상 좌우 전체 외곽 사이 최소 간격은 약 0.301 mm입니다. 인쇄 부풀음·뒤틀림을 포함한 실물 결합 보증은 아닙니다.
좌우 키보드 반쪽끼리 잠그는 기계식 연결은 없으며, 오른쪽 A/B 퍼즐 이음은 별도입니다.

## 출력 방향과 얇은 벽

- mm 단위, 100% 축척으로 출력합니다. 전체 배율 변경은 PCB·나사·스위치 위치를 어긋나게 합니다.
- 하판은 평평한 바닥 외면을 베드에 놓습니다. 바닥 Z가 음수이므로 슬라이서의 베드에 놓기를 적용합니다.
- 상판은 보강판 윗면을 베드에 놓고 벽과 나사 받침이 위로 향하도록 뒤집습니다.
- 0.40 mm 구간은 프린터·노즐·선폭 설정의 확인이 필요한 얇은 벽입니다. 모든 노즐에서 인쇄된다고 가정하지 마세요.
- 슬라이서 층 미리보기에서 얇은 벽이 사라지거나 끊기는지, 상판의 홈·나사 받침이 유지되는지 확인합니다.
- 층 높이 0.20 mm는 시작점일 뿐 확정된 조건이 아닙니다. 재료·베드 접착·수축·강도는 출력 시험으로 결정하세요.
- 자석 홈은 [같은 방향 공차 시험편과 안내](PRINT_magnetic.md)를 먼저 사용합니다. 작은 막힌 홈에 제거 불가능한 서포트를 채우지 마세요.

바닥과 지지부 사이의 이전 공중 틈은 없습니다. 다만 나사 머리 홈과 자석 구멍의 짧은 브리징 등은 슬라이서·출력 확인이 필요합니다.
0.20 mm 이음 여유의 오른쪽 A/B를 먼저 시험 조립하고, 꽉 끼면 나사나 PCB로 강제 정렬하지 마세요.

## USB·POWER·RESET 접근 조건

USB는 상판 위로 열린 **폭 10.20 mm** 통로입니다. 양옆 0.30 mm 여유를 뺀 명목 케이블 폭 가정은 **최대 9.60 mm**입니다.
USB 규격명이 같아도 몰딩 폭·높이·꺾임은 다릅니다. 실제 플러그 몰딩과 헤더 높이를 측정하고, 넓은 몰딩을 억지로 넣지 마세요.
이 가정 밖의 케이블은 별도 간섭 검토가 필요합니다.

POWER에는 외측에서 접근하는 폭 4 mm의 손톱 접근 통로가 있습니다. 손가락 전체 크기를 보증하는 공간은 아닙니다.
RESET은 Ø3.60 mm 구멍과 Ø3.00 mm 이하 비전도성 탐침 접근을 확보했습니다.
실제 컨트롤러·배선이 설치된 상태에서 동작과 안전한 접근을 확인하세요. 금속 공구로 내부를 누르지 마세요.
이 통로는 Z4.10 위에만 있으며 하판 소켓 가림벽을 뚫지 않습니다.

## 조립 순서

1. PCB는 하판 밖에서 납땜합니다. 핀·납·부품이 PCB 아래로 최대 2.90 mm 이내 돌출하는지 실측합니다. 명목 바닥 여유 0.60 mm를 위한 허용 한계이며 실측 결과가 아닙니다.
2. 하판 A/B와 상판 A/B의 퍼즐 이음을 각각 먼저 조립합니다. PCB를 지렛대처럼 사용하지 마세요.
3. 자석 옵션은 극성·접착·이탈을 확인한 뒤 PCB를 올립니다. 무자석 옵션과 외곽은 같습니다.
4. 배터리·헤더·배선이 바닥·핀·벽·나사 사이에 끼이지 않도록 배치하고 PCB를 기존 받침에 올립니다.
5. 공통 MX 상판을 얹고 벽 접합면과 나사 위치를 확인합니다. 벽이 닿지 않는 틈을 나사 힘으로 억지로 닫지 마세요.
6. 명목 M1.4×7.50 mm 나사를 왼쪽 8개, 오른쪽 9개 사용해 균일하게 조입니다. 실제 나사 규격·프린트 나사산·체결 토크는 별도 검증 대상입니다. 8/9/10 mm로 임의 대체하지 마세요.
7. 키캡을 끝까지 눌러 상판·나사 머리와 간섭하는지, 스위치와 소켓이 정상적으로 맞물리는지 확인합니다. MX hat 소켓과 Choc 소켓은 같은 키에 동시에 실장하지 않습니다.
8. 평평한 바닥의 기존 실리콘 발 접착 위치를 사용하되 이음·모서리를 피합니다. 접착·미끄럼 방지 성능은 실제 패드로 확인합니다.

부품 몸체·기능성 핀을 깎거나, 소켓 접점에 납을 흘리거나, 배터리를 압축하여 맞추지 마세요.
전원 전 극성·단락·POWER/RESET을 확인하세요. 키캡 전체 이동, 나사 토크·반복 조립, 2 N 하중 변형, 접착·열·RF 시험은 실물 검증으로 남습니다.
PCB·거버의 재주문이나 새 제작 승인을 의미하는 개정은 아닙니다.
