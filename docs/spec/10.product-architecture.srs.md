### CON-ARCH-001 — X3 interlocked placement clearance for 3D-printed housing

| Field | Value |
| --- | --- |
| Type | constraint |
| Target | kc2-x3 |
| Status | verified |
| Priority | high |
| Tags | kc2 x3 mechanical housing magnet |
| Risk | high |
| Stability | stable |
| Verification Method | Board-coordinate render and kc2-pcb-preflight regression check. |
| GitHub Issue | - |
| Related Docs | docs/spec.md, docs/spec/20.kc2-no-stabilizer-layout.md |

#### Requirement

KC2 X3 shall define an interlocked joined-placement clearance between the left and right PCB Edge.Cuts so the right-side `Y`/`H` protrusion can enter the left-side `T`/`G` recess while the halves can still be used with a 3D-printed bottom housing and magnetic alignment without physical binding. The right-side `Y`/`H` protrusion may locally relieve its horizontal ledges by 0.8 mm while preserving the vertical protrusion face at the 3.6 mm X3 inner-edge margin.

#### Rationale

3D-printed bottom housings can swell or print oversized, and magnets add alignment tolerance. A zero-clearance joined reference is too tight for physical assembly, but a pure bounding-box gap wastes the available T/G and Y/H interlock geometry.

#### Acceptance Criteria

- [x] AC-1: Joined visual and mechanical reference render uses interlocked placement with 1.0 mm minimum Edge.Cuts clearance between the left and right PCBs.
- [x] AC-2: Specification allows 0.8-1.2 mm practical interlocked joined-placement clearance and treats 1.0 mm as the default.
- [x] AC-3: PCB electrical clearance and routing safety are not reduced below the X3 fabrication gate by this placement-clearance change, including the local right `Y`/`H` horizontal ledge relief.

### CON-ARCH-002 — X3 compact controller tab without PCB battery pads

| Field | Value |
| --- | --- |
| Type | constraint |
| Target | kc2-x3 |
| Status | verified |
| Priority | high |
| Tags | kc2 x3 controller compact battery reset |
| Risk | high |
| Stability | stable |
| Verification Method | KiCad Python geometry/power verifier, connectivity verifier, KiCad CLI DRC, kc2-pcb-preflight, fabrication ZIP manifest inspection, and sub-agent review. |
| GitHub Issue | - |
| Related Docs | docs/spec.md, docs/spec/20.kc2-no-stabilizer-layout.md |

#### Requirement

KC2 X3 shall remove the carrier-PCB battery/direct-solder power pad footprint from both halves, route no battery power nets on the PCB carrier, shrink each controller protrusion tab to fit tightly around the nice!nano v2 socket, antenna keepout, USB-C access, and reset tact switch, keep the reset tact switch on the antenna-side controller-tab edge where it remains pressable without entering the nice!nano socket or TW301525 battery reference area, and provide a non-plated battery-lead pass-through slot below the nice!nano v2 B+/B- top-pin area for an optional bottom-side cable exit.

#### Rationale

The previous PCB placed four exposed battery hand-solder pads beside the nice!nano socket, which widened the controller protrusion. Removing those carrier pads allows a tighter controller tab, but it changes the power assembly assumption: the Li-Po leads must be soldered directly to the nice!nano v2 B+/B- pads off the carrier PCB, so the carrier PCB must not contain stale battery nets or exposed power pads.

#### Acceptance Criteria

- [x] AC-1: Both left and right main KiCad boards contain no J_PWR1 footprint, no BAT+/BAT- carrier nets, and no NN_B+/NN_B- carrier pads or traces.

#### Requirement

KC2 X3 shall remove all dedicated M2 screw mounting holes from both PCB halves, use 1.6 mm PCB thickness, support an FDM PLA+ lower housing that primarily captures the PCB by printed ledges/rails rather than adhesive, add nine evenly distributed 3.0 mm NPTH registration and optional M2 clearance holes per half between key switch areas, shift the middle support holes toward the anti-flex center zones, visibly label the support holes as H1-H9, and retreat the PCB Edge.Cuts as far as practical while preserving enough rail land for the printed housing. Each corresponding lower-housing support post shall provide a centered 1.60 mm blind pilot bore for optional M2 self-tapping retention and a 2.55 mm registration peg for PLA print-expansion clearance. The lower housing shall have no front-to-rear slope: its exterior bottom, interior floor top, PCB support plane, wall top, and post/peg tops shall be parallel. The interior shall reserve 2.60 mm below the PCB, comprising the Kailh CPG135001S30 Choc V1 hot-swap socket's 2.20 mm body envelope plus 0.40 mm assembly and FDM tolerance, while retaining a 1.20 mm closed floor for a 3.80 mm total PCB support height. The interior wall shall clear every extracted bottom-side socket body and SMD-pad envelope by at least 0.30 mm laterally. The pilot bore shall open at the peg top and terminate at the flat floor top without penetrating the exterior bottom. Every printable housing STL shall fit within a 150 mm x 150 mm x 150 mm build envelope. The right housing shall therefore be exported as exactly two watertight single-solid STL parts separated by a post-avoiding zigzag glue seam. Each right mating face shall be recessed 0.20 mm from the nominal seam, producing a 0.40 mm nominal assembled gap for PLA expansion and adhesive.

#### Rationale

The user wants the X3 keyboard to remain thinner and visually tighter than the original dedicated M2 screw-fixed version while allowing optional screw retention when rail capture alone is insufficient. Dedicated screw holes and wide perimeter land should remain removed where possible, while the 3.0 mm registration holes, reduced-diameter printed pegs, and blind pilot bores provide repeatable registration, PLA tolerance, and an optional serviceable mechanical fastener path. A sloped floor adds material without increasing bottom-component clearance because the PCB support plane follows the same slope. A flat 3.80 mm support height preserves explicit clearance for the bottom-side Choc sockets and smaller SOD-123 components while removing the unnecessary rear thickness. The 193 mm-wide assembled right housing exceeds the user's 150 mm print-bed axis, so two printable parts are required. A zigzag seam increases the minimum floor bonding length over a straight cut, while the requested 0.20 mm setback on each face prevents PLA expansion from forcing the halves out of alignment.

#### Requirement

KC2 X3 V2 shall provide mutually exclusive assembly modes at every switch position: Kailh Choc V2/PG1353-class low-profile switches are supported only through a bottom-side Choc hot-swap socket, and Cherry MX-style 5-pin PCB-mount switches are supported only through direct-solder through-hole pads. The switch footprint shall not support Kailh Choc V1/PG1350 switches, Choc V2 direct-solder assembly, or MX hot-swap assembly. The board shall use the fixed 71-key stabilizer-free v4 layout defined in docs/spec/20.kc2-no-stabilizer-layout.md, with 32 left keys and 39 right keys, no key wider than 1.75U, and mutually compatible Choc V2 and MX placement geometry. Missing nonstandard keycaps may be produced as target-specific 3D-printed keycaps and are not a reason to enlarge a key beyond 1.75U or add stabilizers.

#### Rationale

The user has Kailh Deep Sea-class switches and wants the next board revision to support Choc V2 low-profile socket assembly while retaining an MX direct-solder fallback. The current X3 board uses a Choc V1/PG1350-focused footprint and cannot be salvaged for Choc V2 by drilling because a 5.0 mm Choc V2 center hole collides with existing routing. Dropping Choc V1 support reduces footprint ambiguity and lets the next revision focus on the two intended assembly modes.

The user validated the general hand position on an existing Choc V1 build and selected the 71-key v4 arrangement after reviewing 1:1 layout previews. The inner 1.5U Enter is the primary Enter because the previous outer-primary position was uncomfortable in actual use. Nonstandard keycap availability is not a layout blocker because missing keycaps can be 3D printed, but the physical design remains stabilizer-free and caps every key at 1.75U.

The user's V1 assembly exposed two additional physical-footprint failures that must not recur: the carrier footprint used the nice!nano board width instead of the center-to-center spacing between its two socket-pin rows, and diode pads were too close to unused hybrid-switch holes and socket geometry for practical hand soldering. V2 therefore treats the controller row spacing and diode solder-tool envelope as fabrication gates rather than relying on nominal pin pitch or ordinary electrical DRC alone.

#### Rationale

The existing Choc V1 housing exposes a wide PCB bezel and a bulky center join, so the joined keyboard still looks separated. The first V2 housing draft also used inaccessible fasteners and a raised cavity even though the intended construction is an extremely thin lower plate. Its plan-only checks missed actual bottom-diode obstruction. Because the design has no switch plate, the PCB needs coplanar perimeter and distributed interior support wherever underside component envelopes permit; PCB retention remains a separate physical-validation problem and must not be confused with the typing-load path.

#### Research / Analysis

- The verified kc2-x3 nine-hole baseline is historical evidence only and does not prove the revised V2 mechanical design.
- User-observed failure modes are excessive visible bezel, an overly open joined center, fasteners that cannot be reached because adjacent switches block the tool, irregular fastener placement, and repeated downward PCB motion during typing.
- The user additionally reported on 2026-08-21 that the prior lower housing could not be assembled because bottom-side diodes occupied material that the plan-only collision report had treated as clear. KiCad inspection confirmed that every V2 diode is a bottom-side SOD-123 footprint and that the hybrid switch also has bottom-side socket and through-board mechanical-pin requirements. Therefore current housing evidence must prove exterior-open three-dimensional cutouts rather than infer assembly from XY support-point separation.
- The official Kailh CPG135001S30 drawing gives the Choc socket depth as `2.20 +/-0.10 mm`; the housing model uses the `2.30 mm` maximum plus `0.10 mm` assembly allowance. The official Vishay 1N4148W SOD-123 drawing gives a `1.35 mm` maximum package depth; the housing model adds `0.30 mm` for the solder fillet. Sources: [Kailh CPG135001S30](https://www.kailhswitch.com/uploads/15927/files/CPG135001S30.pdf), [Vishay 1N4148W](https://www.vishay.com/docs/86356/1n4148w.pdf).
- PCBWay's published standard-PCB capability gives board-outline tolerance as `+/-0.20 mm` for CNC routing and `+/-0.50 mm` for V-scoring. The irregular X3/V2 outline is a CNC-routed case, so two independently fabricated opposing seam edges have a conservative combined differential allowance of `+/-0.40 mm`. On that allowance alone, the current `3.00 mm` nominal straight-seam gap spans `2.60--3.40 mm` before housing registration, keycap-size variation, or measurement uncertainty. Source: [PCBWay PCB capabilities](https://www.pcbway.com/capabilities.html).
- The user reports that the physically fabricated Choc V1 boards from `origin/kc2-choc-v1` felt slightly tight but assembled successfully. The latest branch tip inspected on 2026-08-21 was `9978a03264810f40b856d450a1dce0b7e34b18fb`; its promoted Choc V1 PCB geometry was last changed by `27e1d9b4c87ab669bc46d2df05268e3352309b87`. The committed joined render records a `1.0000 mm` minimum interlocked Edge.Cuts clearance, a documented practical range of `0.8--1.2 mm`, `13.2875 mm` interlock overlap, and `1.8000 mm` horizontal clearance between the annotated cross-seam key envelopes. This is a useful empirical benchmark for an interlocked joint, but it is not a caliper measurement and cannot by itself establish the manufactured edge error or a safe straight-seam V2 target.
- The same Choc V1 branch's housing snapshot (`9ec58222ef7e263c8f592af99367934ac5478358`) used a `2.55 mm` printed registration peg in each `3.00 mm` PCB NPTH hole (`0.45 mm` diametral / `0.225 mm` radial nominal clearance), a `0.10 mm` housing-outline inset, at least `0.31 mm` Choc-socket lateral wall clearance, and `0.20 mm` setback per split-housing mating face (`0.40 mm` assembled housing-part gap). Because the user's historical “slightly tight” observation was not accompanied by caliper data identifying whether the sensation came from the PCB interlock, registration pegs, or housing capture, these values shall remain separately identified rather than collapsed into one inferred tolerance.
- The V2 `1.50 mm` per-side seam inset is therefore not treated as PCBWay process compensation alone. It also creates intentional non-contact between non-interlocking PCB edges and keeps each nominal PCB edge `1.00 mm` beneath the assumed `18.05 mm` MX keycap envelope. Replacing the current `3.00 mm` nominal V2 gap with the historical `1.00 mm` interlocked benchmark requires an explicit geometry decision plus new concealment, housing-registration, and physical-fit evidence.
