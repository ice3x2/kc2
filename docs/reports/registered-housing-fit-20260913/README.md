# 외벽·상판 위치맞춤 및 결합부 개정 검증

대상은 `kc2-x3-v2`, 요구사항은 **CON-ARCH-006, CON-ARCH-007, OPS-ARCH-006**이다. 요구사항의 기준은 [SRS](../../spec/10.product-architecture.srs.md)이며, 이 문서는 기계 설계의 검증 증거를 요약한다.

## 현재 상태

개정 모델의 실제 STEP/STL, Fusion 재출력, 부품 공간, 조립 및 전체 외형 검사가 통과했다. 최종 소스에 연결된 70개 모듈의 356개 회귀시험도 통과했다(239.256초, exit0, errors 없음). **Canonical 발행과 사후 검증, 임시 폴더 없는 격리 검증까지 통과했다.** [게시 확인 기록](publication-confirmation.json)이 최종 manifest와 독립 실행 증거를 연결한다. 실물 적합성 승인은 아니며 첫 출력의 끼움·강도·브리지 품질을 확인해야 한다.

## 변경 범위

- PCB는 이전처럼 하판 위에 놓인다. 기존 소켓 가림벽, 바닥, 70개 키 지지 위치와 17개 나사 위치를 유지하면서 외벽과 상판 위치맞춤 구조를 추가했다. 하판 일반 외벽 상단은 Z=4.10 mm, 위치맞춤 돌기는 Z=5.00 mm이며 상판 홈과의 실제 측면 간격은 0.25 mm다.
- MX, Choc V1, Deep Sea Mini 상판 3종과 공통 하판의 무자석/`magnetic` 2종을 유지한다. 오른쪽은 프린터 크기에 맞춰 A/B로 나뉜다. 발행 목록은 **10 STEP + 10 실제 Fusion F3D + 15 STL = 35 CAD 파일**이다. 기존 링 어댑터는 이 35개 개정 목록에 포함하지 않는다.
- 좌우 중앙 결합은 국소 가이드의 작은 의도된 접촉으로 유격을 줄인다. 실제 조립에서 발견한 불필요한 겹침은 새 왼쪽 외벽·바닥만 국소 절삭해 제거했고, 기존 하판과 실제 결합 돌기 두 개의 손실은 각각 0으로 확인했다.
- 오른쪽 하판 A/B 결합은 2.0 mm 목·4.5 mm 머리와 약0.4 mm 틈을 유지한다. 상판 머리는 4.0 mm다. 얇은 내부 돌출부는 둥글게 정리하고, 하판 수평 이탈 방지는 연속된 1.2 mm 바닥층과 충분한 주변 재료로 검증한다. 나사 체결을 대체하는 영구 잠금 구조로 간주하지 않는다.
- 자석형은 지름2 mm·두께1 mm 자석용 기존 지름2.4 mm/깊이1.2 mm 홈과 뒷벽을 보존하고, 새 외벽을 통과하는 삽입 통로도 검증했다. 자석 면 사이의 명목 간격4.40 mm는 외벽 사이 간격과 다르며, 자력·유지력은 실측하지 않았다.

## 검증 방법의 구분과 보존 이력

실제 CAD 검사는 STEP을 읽어 단면·재료·간섭을 계산했다. 반면 하판의 native feature 보고서10개는 **원본 실제 검사 + 전체 재료의 양방향 차이 정확히0**에 근거한 명시적 증거 전이다. `exact_zero_whole_material_difference`, `native_feature_rerun=false`로 기록하며, native의 각 기능을 다시 계산했다고 주장하지 않는다. 소스·native·실행 코드 연결이 모두 일치해야 전이가 유효하다.

오른쪽 부품 공간의 원래 Boolean 실패값은 삭제하지 않았다. 최종 방법은 무자석형 전체 Z 구간의 실제 단면 검사와 자석형이 그 형상에서만 재료를 제거했다는 실제 증명을 결합한다. 중단된 612쌍 거리 검사를 완료나 PASS로 바꾸지 않았다. 얇은 receiver 돌출부, 정확히0 면적 STL facet, 중앙 외벽의 실제 겹침, 과도한 nominal 돌기 보호 기준 때문에 중단된 시도도 [진단 이력](diagnostics/README.md)에 보존했다. STL 처리는 정확히0 면적 facet만 제거하며, 정상 facet 좌표 변경·welding·hole filling은 하지 않는다.

발행기 STEP 형식 처리 개정 전 통과 보고서들도 별도로 보존했다. 현재 조립·전체 외형·native 전이 보고서는 개정 후 실행한 결과이며, 과거 PASS를 새 코드의 결과로 재사용하지 않았다.

## 아직 소프트웨어가 보증하지 못하는 것

인쇄 수축·팽창, 층간 접착과 작은 연결부 강도, 중앙 마찰·삽입력·반복 수명, 나사 토크, 자석 유지력, 실제 소켓 접점 공차, 선택한 키캡의 전 스트로크 간섭, 배터리 팽창·배선·RF는 실물 확인이 필요하다. 현재 전체 외형 검사는 실제 키캡 조립의 적합성 증명이 아니다. 중앙 국소 외벽의 브리지도 실제 인쇄 품질 확인이 필요하다. 실리콘 발의 배치·접착·무게중심 검토는 사용자 지시로 이번 범위에서 제외했다. 바닥 구조 검증은 제외하지 않았다.

이번 작업은 기계 하우징 개정이며 주문된 PCB/Gerber 16개 파일의 바이트 보존을 최종 발행·사후 검증·격리 검증에서 확인했다. 새 PCB 제작 패키지, 구매·결제 또는 양산 적합성 승인은 포함하지 않는다. `physical_qualified=false`를 유지한다.

## 발행과 재현

최종 파일은 [hardware/MODELS](../../../hardware/MODELS/README.md)에 게시했다. [현재 인쇄 안내](../../../hardware/MODELS/PRINT-registered-housings.md)에서 상판 한 종류와 하판 한 종류를 선택한다. Manifest는 `kc2_registered_housing_manifest.json`이며 71개 보고서와 329개 소스 연결을 기록한다. Git index의 발행 관련 350개 파일도 검토된 바이트와 일치했다.

[격리 실행 기록](isolated-verification.json)은 독립 Git 객체를 가진 별도 저장소에서 516개 파일이 변하지 않았고 `.codex-tmp` 없이 동일한 실제 보고서 검증을 통과했음을 기록한다(exit0, errors 없음, 828.297초). 검증을 게시 사후 검사와 병행했으므로 원본 기록의 candidate 표기는 보존했다. 실제 게시 성공 후 동일 manifest SHA를 대조한 [확인 기록](publication-confirmation.json)이 이를 최종 게시본에 연결한다. 이는 전체 CAD를 새로 생성한 실험이 아니라 게시 증거의 독립 재검증이다.

[REPRODUCE.md](REPRODUCE.md)는 증거 검증과 격리 재생성 순서를 설명한다. 기준 CAD는 Git commit `5b99bcb4567ea1c6bb4f17e54887d4de7614cd03`으로 고정하며, **발행 후 메인 작업 폴더에서 기준 CAD를 요구하는 생성기를 바로 재실행하지 않는다.** 문서화된 절차 자체는 전체 재생성을 새 환경에서 완료했다는 증거가 아니다.
