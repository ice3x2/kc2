# 연속 외벽 결합 방식 비교

요구사항: CON-ARCH-006. 사용자 설명.png의 핵심은 PCB 옆으로 올라온 하판 외벽 자체가
상판과 연속적으로 겹쳐 위치를 잡는 것이다. 기존 세 구간 등록 돌기로 대체할 수 없다.
PCB 윗면 대비 최소1.00 mm 돌출 요구를 SRS Requirement에 반영했다.

**이 문서는 대안 연구이며 수정 STL 배포나 실물 문제 해결 완료가 아니다.**
실제 양쪽/세 종류 상판 STL을 읽어 비교했다. 기존 PCB/Gerber/모델은 수정하지 않았다.

## 높이와 두 방식

PCB 받침 Z2.50 및 PCB 윗면 Z4.10은 유지한다. 초기 권장 검토값은
하판 벽 끝 Z5.60(PCB보다1.50 mm 높음), 상판 아래 Z4.40 대비 명목 겹침1.20 mm이다.
최소 요구1.00 mm에0.50 mm 설계 여유를 더한 것이며 제조 오차 보증이 아니다.

| 비교 | 상판 아래 홈/단차에 하판 벽 삽입 | 하판 외벽 안으로 상판 측면 삽입 |
| --- | --- | --- |
| 위치맞춤 | 여러 방향의 연속 측면이 겹쳐야 함 | 여러 방향의 연속 측면이 겹쳐야 함 |
| 상판 위 잔여 재료 | 홈 지붕 필요 | 외측 개방 겹침이면 홈 지붕 불필요 |
| 기존 외곽 유지 | 상대적으로 유리하나 내부 스위치 보호공간 검토 필요 | 상판을 보존하면 외측에 새 벽/틈 공간 필요 |
| 저상형 | 깊은 홈으로 얇은 지붕 발생 가능 | 지붕 문제를 피할 수 있음 |
| 중앙 좌우 | 중앙 예외 처리 필요 | 전체를 둘러싸면 서로 간섭; 중앙 예외 필수 |
| 출력 | 홈 천장/잔여벽/출력 방향 확인 필요 | 연속 상승벽 뿌리/변형/모서리와 분할 확인 필요 |

두 방식 모두 손으로 억지 압입하는 구조나 걸쇠가 아니다. Z방향 고정은 나사가 담당하고
기존 PCB 받침/상판 나사 받침이 Z하중을 받는다. 벽 끝을 상판에 눌러 높이를 정하지 않는다.

## 홈 지붕 계산

벽 끝5.60에 공학적 천장 여유0.30을 더하면 홈 천장은 Z5.90이다.

| 상판 | 기존 판 윗면 | 홈 위 남는 두께 |
| --- | --- | --- |
| MX | 9.30 mm | 3.40 mm |
| Choc V1 | 6.50 mm | 0.60 mm |
| Deep Sea | 6.25 mm | 0.35 mm |

이는 수직 치수 계산이다. MX도 실제 홈이 스위치 몸체/나사/서비스 공간을 침범하지 않고
상판에 연결되는지는 별도 검증해야 하며 이 표만으로 구현 가능 판정을 내리지 않는다.
과거 얇은 가림벽이 부러졌던 문제를 고려하면 저상형0.60/0.35 mm 지붕을 아무 근거 없이
튼튼한 것으로 채택할 수 없다. 시험의1.20 mm 지붕 비교값은 보수적 연구 기준이며
재료 강도 시험 결과나 모든 면에 동일하게 적용되는 기존 SRS 최소값은 아니다.

## 실제 외곽을 감쌌을 때

현재 상판 STL의 각 정점 높이 구간 중간 단면에서 외곽을 추출하고 합집합하여
평면 외피를 만들었다. 조립 틈0.30 mm와 벽 두께1.20 mm의 단순 외측 감싸기 후보는
**현재 상판 외곽보다 각 방향으로1.50 mm 더 바깥에 공간을 요구**한다.
이는 기존 하판 전체 외곽 대비 항상1.50 mm 증가한다는 뜻이 아니다.
오른쪽 수치는 A/B 합친 범위이며 개별 출력물150 mm 검증으로 해석하면 안 된다.

중앙까지 그대로 둘렀을 때 반대쪽 후보 벽과의 평면 교차면적은
MX60.9060 mm², V1약76.9068 mm², Deep Sea약76.9069 mm²이다.
따라서 무조건360도 두르는 후보는 탈락이며 중앙 결합면을 제외해야 한다.
이 수치는 임시2D 외피 충돌이며 최종 수정 CAD 간섭 검증이 아니다.
USB/PWR/RST, 케이블 및 오른쪽 A/B도 이 단순 후보에는 아직 반영하지 않았다.

MX와 저상형 상판 외곽이 서로 다르므로 공통 하판을 유지하려면 상판 둘레의
결합부를 공통 위치에 맞추거나 별도 하판이 필요하다. 빈틈이 큰 저상형을
그대로 넣고 흔들리지 않는다고 주장하지 않는다. 기존 무자석/magnetic 옵션도 유지한다.

## 판단 및 구현 전 결정

권장하는 방향은 **중앙/서비스를 제외한 둘레를 감싸되, 상판 측면의 아래 부분만
약1.20 mm 높이로 겹치는 외측 개방 겹침 구조**이다. PCB보다 벽은1.50 mm 높게 한다.
이는 저상형의 얇은 홈 지붕을 피하는 데 유리하다. 단, 최종 CAD/강도/캡 간섭 합격은 아니다.

상판의 **전체 높이**를 덮는 높은 담장은 별개의 대안이다. MX의 판 윗면까지라면
PCB 위5.20 mm가 필요하고 저상형 공통 하판으로 쓰기 어렵다. 미제공 키캡 스커트와
전체 이동을 침범할 수 있으므로 단지 더 높다는 이유로 추천하지 않는다.

외측 감싸기는 기존 '키캡이 PCB/하판 외곽을 가리는' 외관 제한과 충돌할 수 있다.
상판을 보존하는 단순 후보는 바깥으로1.50 mm 공간을 쓰므로, 보이는 테두리 확대를
허용할지 사용자 선택이 필요하다. 허용되지 않으면 기존 외곽 안쪽의 홈 방식으로
종류별 벽/홈과 상판 단면을 다시 설계해야 한다. 강도나 보호 공간을 줄여 억지로 맞추지 않는다.
