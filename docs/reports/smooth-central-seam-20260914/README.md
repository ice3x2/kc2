# 중앙 요철 자리의 파임 메우기

요구사항: `CON-ARCH-006`, `CON-ARCH-007`, `OPS-ARCH-006`.

이전 개정은 돌출 요철만 잘라내어, 탄성 안내부가 움직이도록 비워 둔 외벽과 바닥의 공간이 남았다. 이번 수정은 그 공간을 기존 외벽과 바닥 단면에 맞춰 메운다.

각 하판의 Y=95,117 mm에서 폭 6.20 mm 구간을 복원한다. 외벽은 왼쪽 X=-1.50..-0.30, 오른쪽 X=149.70..150.90 mm이고 Z=-2.20..4.10 mm이다. 바닥 복원은 기존 외벽 안쪽 3.20 mm 폭, Z=-2.20..-1.00 mm에 한정한다. 기존 두께와 외곽 안에서 빠진 재료만 추가하며, 부품 보호 공간과 PCB 여유를 먼저 확인한다.

검증 자료는 이 디렉터리의 generation, review, native-generation, native-review, tests 기록과 [STL 실제 단면 비교](wall-sections.png)에 있다. 원본 바이트와 최종 출력물은 `hardware/MODELS/kc2_smooth_central_housing_manifest.json`으로 연결한다. 이전 입력 형상은 Git `9e0bb01`에 보존한다.

검증 범위는 실제 STEP 재열기, 기존 재료 보존과 추가 영역 제한, 실제 STL 폐쇄성 및 외벽/바닥 단면 연속성, 맞은편 하우징과 새 재료의 간섭, 우측 A/B 간격, 실제 Fusion 저장·재열기·STEP 재출력 일치이다. 상판, 기존 자석 및 부품 보호 영역 밖의 재료는 변경하지 않는다. 실물 강도·출력 공차·자석 고정력은 별도 출력 시험이 필요하다.

실제 재료 추가량은 일반형/자석형 각각 왼쪽 29.448 mm³, 오른쪽 25.4529974 mm³이다. 기존 재료 삭제, 복원 범위 밖 추가와 STEP 복원 누락은 모두 0 mm³이다. 실제 STL 단면 누락 최대치는 0.000000544 mm²로 STL 좌표 정밀도 범위이다. 새 재료와 맞은편 하우징 사이 최소 간격은 0.800 mm, 교차 체적은 0 mm³이다. 우측 A/B 실제 간격은 기존과 동일한 0.400031432 mm이다. 관련 회귀시험 23개와 Git 바이트 보존 시험 2개가 통과했다.
