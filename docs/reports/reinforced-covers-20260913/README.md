# 가림벽 파손 대응 보강 검증

요구사항: `CON-ARCH-006`, `OPS-ARCH-006`; 조립 기준 보존: `CON-ARCH-007`.

사용자가 기존 약 0.40 mm 가림벽의 출력 후 파손을 보고했습니다. 이번 개정은 하판과 MX 상판의 국소 가림벽을 명목 1.20 mm, 바닥·판 연결 겹침을 0.80 mm로 보강합니다. 기존 PCB 안착 높이, 소켓 공간, 체결 위치, 좌우 결합 위치와 무자석/자석 선택을 유지합니다. 주문된 PCB와 거버는 변경하지 않습니다.

이전 2026-09-10 검증 기록은 얇은 벽의 과거 디지털 증거이며 이번 보강 형상 또는 실물 강도에 대한 증거로 사용하지 않습니다.

보강 출력물의 개별 형상·조립·native 검증이 통과했습니다. 최종 게시 여부와 파일 일치는 `hardware/MODELS/kc2_local_cover_manifest.json`의 이 디렉토리 증거 연결 및 `python -B -m tools.publish_kc2_local_covers --verify` 결과로 확인합니다. 실제 출력 강도와 구매 부품의 조립 적합성은 재출력 확인 전까지 미검증입니다.

## 검증 범위

108개 소스 고정 회귀 테스트가 통과했습니다. 기존 0.40 mm 벽을 새 보강 벽으로 이름만 바꾸어 통과시키는 경우, 두께/연결 겹침 부족, 원래 받침 삭제, 전역 외벽 추가, 누락된 모서리와 잘못된 분할 등을 거부하는 테스트를 포함합니다. 실제 STEP/STL 검사 및 Fusion 재열기 검사는 별도 증거입니다.

Fusion 6개 F3D의 저장·재열기와 진단 STEP 재내보내기가 완료됐습니다. 동일 커널의 적응형 체적/치수 비교도 여섯 모델 모두 통과했습니다. 이는 파일 변환 시 형상 보존에 대한 증거이며 재출력 강도에 대한 증거가 아닙니다.

MX 상판의 좌우 실제 STEP/STL 검토가 통과했습니다. 세 인쇄 부품 모두 원본 삭제·요청 가림부 누락·허용 영역 밖 추가·보호 부품/서비스 공간 간섭은 0 mm³이고, 새 서비스/드라이버 접근 방해가 없습니다. 오른쪽 원본 부품 간, 보강 부품 간, 추가부와 맞은편 원본 간 및 추가부끼리의 거리는 모두 0.19975909123481658 mm로 기존 명목 0.20 mm 분할 여유를 보존합니다. 기존 서비스 접근 한계와 실제 출력 오차는 별도입니다.

좌우 하판의 무자석/자석 버전 실제 검토도 통과했습니다. 기준 r5 대비 추가 재료는 왼쪽 485.607831 mm³, 오른쪽 658.100031 mm³로 각 옵션에서 동일합니다. 원본 삭제, 허용 영역 밖 추가, 가림부 누락, 소켓/부품 및 나사 파일럿 침범은 모두 0 mm³입니다. 기존 자석 홈과의 차이도 추가/누락 모두 0 mm³입니다. 하판 6개 STL은 각각 닫힌 단일 몸체이고 STEP 형상 및 150 mm 출력 범위 검사에 통과했습니다. 오른쪽 기존 분할선의 국소 보강부 생략 면적 0.3852 mm²는 원래 0.20 mm 이음 여유에만 해당하며, 그 밖의 가림부 누락은 없습니다. 검사 시작/종료 소스 해시가 일치합니다.

네 실제 형상 검토를 묶은 전체 조립 검토도 통과했습니다. 기존 오른쪽 이동 X124.625/Y0에서 전체 하우징 평면 외곽의 최소 좌우 간격은 0.446 mm, 겹침은 0 mm²입니다. 하판 6개 STL의 무부품 무게중심은 원래 실리콘 발 지지 영역 안에 있습니다. 완전 실장 상태의 안정성과 실제 FDM 오차는 이 값으로 검증된 것이 아닙니다.

이 개정의 연결부 보강은 가림벽과 바닥·MX 판의 접합 겹침 확대입니다. 추가 요청된 “이음 부분”이 오른쪽 A/B 맞물림 돌기를 뜻하는지는 사용자에게 확인 요청했습니다. A/B 돌기 폭 확대·위치 이동은 사전 검토만 했으며 현재 형상에는 적용하지 않았습니다. 좌우 키보드를 기계적으로 잠그는 구조는 추가하지 않습니다.

출력 파일은 하판 6개 STL(일반형 3개 또는 자석형 3개 중 선택)과 공통 MX 상판 3개 STL입니다. STEP/F3D는 각 6개이며 오른쪽 전체 파일에는 분할된 두 솔리드가 들어 있습니다. 출력 개별 부품의 최대 평면 치수는 약 137.667 mm로 150 mm 범위 이내입니다. 바닥은 기존 1.20 mm, PCB 아래/위는 Z2.50/4.10, MX 판 아래/위는 Z7.80/9.30, 가림벽 아래 끝은 Z4.40을 유지합니다.

새 가림벽은 스위치·소켓의 기존 보호 공간을 채우지 않도록 바깥쪽으로 보강합니다. 스위치 몸체 보호 영역은 15.6 mm 기준이며, 키캡 안쪽 형상·실제 납땜 돌출·수령 부품 편차는 이 디지털 모델만으로 합격 처리하지 않습니다. 컨트롤러 서비스 방향의 기능상 개구부는 유지하며 기존 구조의 도구 접근 제한을 제거했다는 뜻이 아닙니다.

## 재현

각 side `left`/`right`에 대해 `tools.generate_kc2_local_covers`, `tools.kc2_local_upper_covers`로 생성하고 `tools.review_kc2_local_covers`, `tools.review_kc2_local_upper_covers`로 실제 STEP/STL을 검토합니다. 임시 생성 경로는 `.codex-tmp/reinforced-cover-build`입니다. 네 검토 통과 후 `tools.review_kc2_local_assembly`를 실행합니다.

Fusion에서 `KC2LocalCoversToF3D`로 여섯 파일을 내보내고 다시 엽니다. `KC2LocalNativeReview`의 `all` 작업은 F3D에서 검사용 STEP을 내보냅니다. `tools.review_kc2_local_native --label all`은 동일 커널과 적응형 체적 적분으로 원본/검사용 STEP을 비교합니다. 허용 오차는 기존과 동일하게 치수 0.001 mm, 체적 max(0.002 mm³, 원본 체적×1e-6)입니다. 검사용 `native-check-*.step`은 증거이며 인쇄/편집할 별도 활성 모델이 아닙니다.

`tools.collect_kc2_local_cover_tests`의 소스 고정 회귀 결과와 모든 형상·native 증거가 통과해야 `tools.publish_kc2_local_covers --apply`로 `hardware/MODELS`를 갱신할 수 있습니다. `--verify`는 임시 파일·Fusion·CadQuery 없이 게시된 실제 바이트와 증거 연결을 검사합니다. PCB/거버 16개 파일의 원본 바이트도 보존 검사합니다.
