# KC2 평면 중앙 이음 개정 검증

요구사항: `CON-ARCH-006`, `CON-ARCH-007`, `OPS-ARCH-006`.

## 결과

- 일반형과 자석형 하판에서 중앙 비잠금 안내/마찰 요철 두 쌍(`Y=95, 117 mm`)을 모두 제거했다.
- 변경은 기존 면 밖으로 돌출된 재료의 감산뿐이다. 제거량은 좌측 각 `20.128 mm³`, 우측 각 `21.584 mm³`이며 추가 재료, 허용 창 밖 삭제, 과거 보호 재료 삭제와 남은 돌출부는 모두 `0 mm³`이다.
- 자석형의 기존 두 쌍(`Y=103, 111 mm`)과 전체 자석 감산 체적 `21.7146884216 mm³/측`은 그대로다.
- 컨트롤러 쪽 세 번째 자석 쌍은 추가하지 않았다. `0.1 mm` 간격으로 조사한 유효 범위에 안전하게 정렬되는 후보가 없었다. `Y=92 mm`의 가장 가까운 후보는 좌측 필요 잔여 재료가 `0.0972156518 mm³` 부족했고, `Y=97 mm`는 양쪽 모두 `4.5770181305 mm³` 부족했다. 안전한 원거리 구간의 자석 면 간격은 약 `31.9125 mm`여서 유효 흡착 위치가 아니다. 외벽 확대 금지 조건을 지켜 무리하게 추가하지 않았다.
- 네 STEP과 여섯 STL을 독립 재개방했다. 몸체 수, 유효성, 예상 감산 형상, 메시 체적/경계, watertight 단일 shell과 150 mm 출력 범위를 확인했다.
- Fusion `2705.1.11`에서 네 STEP을 F3D로 저장하고 다시 열어 STEP readback까지 수행했다. 모든 몸체의 체적·표면적·중심·경계가 일치했다.
- 35개 현재 CAD 파일 중 하판 14개만 교체하고 상판 21개는 바이트 그대로 유지했다. 주문된 PCB/Gerber 16개도 바이트 그대로 유지했다.
- 기존 하우징 회귀 356개와 이번 개정 회귀 21개, 총 377개가 통과했다.

## 게시 위치

- 현재 manifest: `hardware/MODELS/kc2_flat_central_housing_manifest.json`
- 인쇄 안내: `hardware/MODELS/PRINT-flat-central-housings.md`
- 실제 인쇄 파일: `hardware/MODELS/*.stl`

현재 상태는 `digitally_verified_physical_pending`이다. 출력 팽창·수축, 자석 접착/흡착력, 실제 좌우 감촉과 장기 강도는 시험 출력 후 확인해야 한다.
