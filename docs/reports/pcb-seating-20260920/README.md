# PCB 안착 및 보강판 위치맞춤 재점검

대상: `CON-ARCH-006`, 현재 `hardware/MODELS`의 smooth-central 하판.

**실물 안착 불량은 해결되지 않았다. 이 보고서는 재출력 승인이나 개선 STL 배포가 아니다.**
사용자는 PCB가 외벽 위에 올라가 상판 홈이 물리지 않는다고 보고했다.
현재 CAD가 명목 치수상 통과한다는 사실로 실물 불량 보고를 기각하지 않는다.

## 확인 결과

현재 설계 좌표는 PCB 받침 Z2.50, PCB 두께1.60, PCB 윗면 Z4.10 mm이다.
일반 외벽 끝은 Z4.10, 위치맞춤 벽 끝은 Z5.00, 상판 홈은 Z4.40..5.20이다.
따라서 PCB 두께를 누락한 설계는 아니며 명목 물림은0.60 mm이다.
높이는 하판 외부 바닥 Z-2.20 기준의 캘리퍼 측정값과 구분해야 한다.
하판 외부 바닥부터 PCB 받침까지는4.70 mm, 정상 PCB 윗면까지는6.30 mm이다.

현재 PCB 외곽과 실제 STL의 Z2.50 위 모든 서로 다른 정점 높이 구간의
중간 단면을 대조했다. 네 하판 모두 두 구간(Z3.30,4.55)에서 기판 교차면적0이다.
왼쪽 최소 여유0.2999965 mm, 오른쪽0.2999918 mm이며 자석 유무에 따른 차이는 없다.
이 영역에 별도 유도 테이퍼를 제공하는 중간 높이 형상은 확인되지 않았다.
Z2.49 단면에는 기판 아래 받침 재료가 존재한다.
이는 정렬된 맨기판 외곽 검사이지 실장 소켓/납땜부의 실물 안착 보증이 아니다.

## 오차 민감도 — 제조 공차 보증값 아님

| 가정한 둘레 방향 합산 오차 | 남은 최소 여유 | 판단 |
| --- | --- | --- |
| 0.00 mm | 약0.30 mm | 명목 비접촉 |
| 0.10 mm | 약0.20 mm | 비접촉 |
| 0.20 mm | 약0.10 mm | 비접촉 |
| 0.30 mm | 사실상0 | 접촉 한계; STL 수치 근사 포함 |
| 0.35 mm | 0 | 양쪽 모두 겹침 발생 |

위 오차는 기판 외곽을 균등 확장한 민감도 시나리오다. 특정 프린터의 수축률,
기판 제조 공차, 조립 위치 오차를 실측하거나 확정한 값이 아니다.
XY 오차는 기판이 못 내려가는 원인이 될 수 있지만 그 자체가 실제 원인이라는 증거는 없다.

기판이 정상 받침에서0.20 mm 뜨면 상판도 같이 올라간다는 가정에서 홈 물림은0.40 mm,
0.40 mm 뜨면0.20 mm,0.60 mm 이상 뜨면0이다.
일반 외벽 Z4.10에 기판 아랫면이 걸리면 정상보다1.60 mm 높아져 홈 물림이 사라진다.
그러나 정상 안착을 복구하지 않고 벽만1.60 mm 높이는 것은 이 문제의 해결로 인정할 수 없다.
PCB/스위치/나사 높이, 상판과 서비스 간섭을 별도로 바꾸는 결과도 생길 수 있다.

## 수정에 필요한 실물 구분

1. 출력한 하판 STL 파일명과 기판을 올린 옆면 사진을 확인한다.
2. 기판 모서리가 외벽 **안쪽으로 내려갔는지**, 외벽 **위에 걸쳤는지** 확인한다.
3. 가능하면 하판 외부 바닥에서 PCB 윗면까지 높이를 측정한다(설계6.30 mm).
4. 외곽이 들어가도 뜨면 아래 소켓/핀/납땜부의 접촉 위치를 찾는다. 나사로 강제 압착하지 않는다.
5. 둘레 끼임이면 해당 위치의 입구/안쪽 여유를, 하부 접촉이면 해당 부품 공간을 수정한다.
   정확한 원인이 없는 상태에서 전체 축척, PCB 받침 높이 또는 벽 전체 높이는 변경하지 않는다.

## 재현 및 한계

`C:/Python312/python.exe -B -m unittest tools.test_kc2_pcb_seating` — 4개 시험 통과.
시험을 먼저 추가해 모듈 부재로 실패한 뒤 구현했다. 시험용 연결되지 않은 상자 조합의
잘못된 단면 기대값은 실제 폐곡면 링 fixture로 고쳐 내부 빈 공간 보존을 검증했다.
높은 위치의 삽입 장애물 검출, 정상 받침 제외, 추가 PCB 높이에 따른 물림 상실을 포함한다.

`C:/Python312/python.exe -B -m tools.kc2_pcb_seating` — [sections.json](sections.json).
실제 STL 및 PCB 입력 SHA-256을 기록하고 실행 도중 변경 여부를 확인한다.
정점 높이 구간의 수평 표본 검사이며 일반적인 연속 swept-volume 증명은 아니다.
상판 물림 민감도는 설계 좌표 계산이며 이번 실행에서 상판 STL을 새로 측정한 결과는 아니다.

기존 게시물 검증 `tools.publish_kc2_smooth_central_seam --verify`도 통과했다.
PCB, 거버, STL/STEP/F3D는 변경하지 않았다. 실물 문제는 미해결이며 SRS 상태도
`in_progress`로 유지한다. 본 보고서는 새 제작 발주 승인과 무관하다.
